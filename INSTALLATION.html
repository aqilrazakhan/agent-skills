taa-skill-vetter

v1.0.1

Security-audits a third-party agent skill before you install it. It quarantines the skill, checks the publisher, runs a static scan, requires a full manual read, and returns a verdict. It never runs the code it audits.

PASSREVIEWFAIL
Repository Release v1.0.1 Report an issue

Install a tagged release, not main. Pinning is the same advice the skill gives about everyone else's skills, and it means you get exactly the code that was reviewed.

Requirements

  • An agent that supports skills: Claude Code, claude.ai, or any agent supported by the skills CLI.
  • Python 3.9 or newer on the machine that runs the audit. The scanner uses the standard library only.
  • git and network access to GitHub, so the skill can clone what it audits.
  • Node.js, only for the skills CLI route.

Install

Add the marketplace pinned to the tag, then install the plugin.

claude plugin marketplace add aqilrazakhan/agent-skills@v1.0.1
claude plugin install taa-skills@aqilrazakhan-agent-skills

Check it with claude plugin list. You should see taa-skills@aqilrazakhan-agent-skills, version 1.0.1, enabled. In a session, run it as /taa-skills:taa-skill-vetter.

List what the repo contains without installing anything:

npx skills add aqilrazakhan/agent-skills#v1.0.1 --list

Install for the agents you choose:

npx skills add aqilrazakhan/agent-skills#v1.0.1 --skill taa-skill-vetter

Claude Code only, available in every project:

npx skills add aqilrazakhan/agent-skills#v1.0.1 --skill taa-skill-vetter -a claude-code -g

Check with npx skills list.

  1. Download the v1.0.1 release, or clone the tag:

    git clone --depth 1 --branch v1.0.1 https://github.com/aqilrazakhan/agent-skills.git

  2. Read skills/taa-skill-vetter/. It is small: SKILL.md, two reference documents, a signatures file and one Python script.

  3. Copy the folder to ~/.claude/skills/taa-skill-vetter/ for all your projects, or <project>/.claude/skills/taa-skill-vetter/ for one project (preferred).

  1. Zip the skills/taa-skill-vetter/ folder. Zip the folder itself, not just its contents.

  2. Upload the zip in claude.ai's skill settings.

Use it

Ask your agent in your own words:

Audit aqilrazakhan/some-repo --skill some-skill before I install it
Vet the skill in ./downloads/cool-skill
Re-audit every skill installed in ~/.claude/skills

Each audit produces a skill-audit-<name>-<shortsha>.md report with the verdict, the exact commit audited, the scanner findings and how each was judged.

The scanner also runs on its own:

python3 -I skills/taa-skill-vetter/scripts/scan_skill.py <skill-dir> --md report.md --json report.json
# exit code: 0 PASS, 1 REVIEW, 2 FAIL

A scanner PASS is not proof of safety. The skill also requires a full manual read of every file.

Update and uninstall

Releases are on the releases page. Before moving to a new version, read the changelog and diff it like any other third-party skill, ideally by auditing it with this skill. Then repeat your install command with the new tag.

git diff v1.0.1..<new-tag> -- skills/taa-skill-vetter

Update

  • Plugin: remove the marketplace, add it again with the new @<tag>, and reinstall.
  • skills CLI: rerun the install with #<tag>. npx skills update moves to the latest version, not a tag you have reviewed.
  • Manual or claude.ai: replace the folder with the new tagged copy.

Uninstall

claude plugin uninstall taa-skills@aqilrazakhan-agent-skills
claude plugin marketplace remove aqilrazakhan-agent-skills
  • skills CLI: npx skills remove taa-skill-vetter
  • Manual: delete the folder you copied.

Troubleshooting

python3: command not found, or a syntax error from the scanner

Install Python 3.9 or newer.

The marketplace name already exists

Claude Code allows one marketplace per name. Run claude plugin marketplace remove aqilrazakhan-agent-skills, then add the pinned one.

The audit cannot clone the target

The skill asks you to attach the folder or zip instead. Private repositories need git credentials on the machine.

Scanner hits when scanning this skill itself

Expected. references/signatures.json and references/review-checklist.md describe the attacks being detected, so they match their own patterns.

A false positive or a missed attack

Open an issue at github.com/aqilrazakhan/agent-skills/issues with the pattern and, if possible, a minimal inert example.
